# v0.1.0-alpha.8

接続状態と障害復旧を改善し、Cloudflare設定画面をDSHの共有部品で作り直しました。開発プレビューを継続します。

## 変更内容

- オンライン状態をゲートの待受とcloudflaredの接続で判定します。タブを閉じても接続障害と表示しません。実通信の確認日時は別に表示します。
- 一時停止を保存し、DSH再起動後も維持します。取消しは実行中の処理だけを中断します。
- 起動時の再接続失敗と稼働中のcloudflared終了から、保存済みトークンで自動復旧します。未認証アクセスが成功した場合などは停止を維持します。
- 結果不明のPOSTを、Cloudflare上の識別情報を読み直して設定画面から解消できます。資源を削除する操作はホスト名の再入力が必要です。
- 初回設定を3段階に整理しました。公開URLからの設定画面は読み取り専用です。
- プラグインが追加したtrustedHostsを公開設定の削除時に戻します。ホスト識別、所有権ロック、署名検証鍵の一時的な取得障害への対応も改善しました。
- OAuth、設定画面内の自己更新、専用の所有者確認リンクを削除しました。更新はDSHのプラグイン管理から行います。日本語表示には日本語を登録する言語パックが必要です。

## レビューで修正した問題

- 追加認証の変更が反映された後に読み戻しだけ失敗すると、再試行が認証方式の不一致で止まっていました。明示した変更先の方式を、所有権・audience・IdP・所有者ポリシーとともに再検証し、反映済みならPUTを再送せず続行します。
- 再開時の保存中に取消し・一時停止を操作すると、遅れて接続が始まる競合がありました。保存を取消し対象の処理に含め、一時停止は処理の終了を待って保存します。

## 導入・更新

```sh
dsh plugin --profile web add -w 'github:Aero123421/dsh-cf#v0.1.0-alpha.8'
```
