# v0.1.0-alpha.6

Cloudflare経由の接続を簡単にし、設定画面とREADMEを整理しました。

## 変更内容

- 通常のCloudflare Accessログインを標準にしました。追加のWebAuthn認証は詳細設定から選べます。既存の追加認証設定は維持し、明示的に変更した場合だけ切り替えます。
- 専用Accessアプリのログイン期限を1週間（168時間）にしました。既存のCookieは発行時の期限が続き、次回ログインから反映されます。競合するポリシーは上書きせず停止します。
- 公開URLを開くとAccessで本人を確認し、DSHの認証へ自動で進みます。通常の利用で別の所有者確認URLを開く必要はありません。
- 接続状態、公開URL、「DSHを開く」を中心に画面を整理しました。設定済みの項目、詳細設定、診断、更新は折りたたみました。
- 初回設定で候補が1つなら自動選択し、公開ホスト名を提案します。認証エラーには復旧手順を表示します。
- Cloudflareの組織APIで、省略された任意のAMR設定を正しく扱うよう修正しました。不正な設定や認証の代替を許す設定は引き続き拒否します。
- READMEを初回設定・普段の使い方・問題の解決順に書き直し、詳しい仕様を別ページへ移しました。

Access JWTの本人・署名・有効期限の検証、管理操作のlocalhost制限は継続します。APIやWebSocketから初回の認証を開始することはできません。

## 導入

```sh
dsh plugin --profile web add -w 'github:Aero123421/dsh-cf#v0.1.0-alpha.6'
```

導入後はDSHを再起動してください。ソースから導入するため、添付ファイルは不要です。設定変更時は管理用APIトークンを再入力します。
