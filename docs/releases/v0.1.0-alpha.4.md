# v0.1.0-alpha.4

Cloudflare設定にプラグインの実行版・導入版、安定版／プレリリースの選択、更新確認・明示的な導入操作を追加します。

更新先は固定repositoryのリリースタグです。ソースのJSから導入でき、Release assetやビルドは要求しません。対象package・版・entry・bundleと対応DSHを確認し、導入版を下げません。現在のGitHub導入経路とbundleの有効状態を維持します。

操作記録をprofile別に保存し、切断後は同じ要求を再送せず照合します。別のprofileに切り替えた場合はブラウザの操作IDを持ち込みません。再起動待ち・実行版確認・失敗・取消・上書き・結果不明を区別します。

更新は元のローカル管理接続だけで実行できます。公開Tunnelの管理制限、Host・Origin・認証、Cloudflareの所有IDと既存設定を維持します。cloudflaredやクラウド資源を更新機能から操作しません。

検証コマンドと結果はPRに記録します。実Cloudflareアカウント、Tunnel接続、Windows/macOS実機、Electronは今回未検証です。Worker・DB・サービス・CI・クラウド資源の作成やdeployは行っていません。
